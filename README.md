# pedro-ruan-lp1-2026

Este repositório contém códigos em C para atividades da disciplina LP1.

## Estrutura do Projeto
- `atividades/`: Pasta com atividades individuais:
  - `contarCaracteres.c`
  - `imprimirFatorial.c`
  - `imprimirNumeros.c`
  - `numeroPrimo.c`
  - `temperatura.c`
- `este arquivo`

## Como Compilar e Executar com GCC

### Passo a Passo

1. **Navegue para a raiz da pasta de atividades**:
   ```
   cd atividades
   ```


2. **Para cada atividade na pasta `atividades/` faça como o exemplo abaixo:**:
   - **exemplo atividade**:
     ```
     gcc atividadeDestinada.c -o atividadeDestinada -Wall
     ./atividadeDestinada
     ```


## Notas
- Use `-Wall` para ver avisos durante a compilação: `gcc -Wall main.c -o main`
- Certifique-se de que os arquivos `.c` não tenham erros de sintaxe.
